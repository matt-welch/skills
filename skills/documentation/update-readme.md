# Skill: Update README

## Description

Create or improve a project README so that new contributors and users can quickly understand what the project does, how to set it up, and how to contribute.

## Usage

Provide the project name, purpose, and any existing README or documentation. This skill will produce a README with the following sections (as applicable):

- **Title and badges** – project name, CI status, license, and version badges
- **Description** – what the project does and who it is for
- **Features** – key capabilities in a scannable list
- **Prerequisites** – required tools, runtimes, or accounts
- **Installation** – step-by-step setup instructions
- **Usage** – how to run or use the project with examples
- **Configuration** – environment variables, config files, or flags
- **Contributing** – how to file issues, run tests, and submit pull requests
- **License** – license name with a link to the full text

## Example Prompts

- "Write a README for our new Go CLI tool."
- "Our README is outdated—refresh it to match the current state of the project."
- "Add a Contributing section and a badge table to the existing README."

## Notes

- Assume the reader is a competent developer who is unfamiliar with the project.
- Verify that all commands in the README actually work before publishing.
