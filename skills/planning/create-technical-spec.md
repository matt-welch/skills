# Skill: Create Technical Specification

## Description

Generate a structured technical specification document for a new feature, service, or system component. The spec covers requirements, design decisions, edge cases, and implementation notes.

## Usage

Provide context about the feature or system, and this skill will produce a spec covering:

- **Overview** – problem statement and goals
- **Requirements** – functional and non-functional requirements
- **Design** – proposed architecture or approach
- **API / Interface** – public contracts or interfaces
- **Edge Cases** – known limitations or special handling
- **Open Questions** – unresolved decisions to discuss

## Example Prompts

- "Write a technical spec for a rate-limiting middleware."
- "Create a spec for adding OAuth2 login to our API."
- "Draft a spec for migrating our database from PostgreSQL to CockroachDB."

## Notes

- Tailor the level of detail to the audience (engineering team, stakeholders, etc.).
- Flag assumptions explicitly so they can be validated before implementation begins.
